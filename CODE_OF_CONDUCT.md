# Code of Conduct

## Our standard

Be decent. This is a small developer tool with a simple social contract:

- **Critique code, not people.** Feedback should target the change, not the author.
- **Assume good faith.** Questions are not attacks; mistakes are not character flaws.
- **Help people help themselves.** Point at docs, rule pages, and repro steps instead of just "works for me".
- **Respect that contributors are volunteers.** No one owes you a timeline.

Unacceptable: harassment, hate speech, trolling, publishing others' private information, or any conduct a reasonable person would call hostile.

## Scope

Applies to the issue tracker, pull requests, discussions, and any other project space.

## Enforcement

Maintainers may remove, edit, or reject contributions that violate this document, and may temporarily or permanently ban contributors for serious or repeated violations.

Report problems to the maintainers via a GitHub issue tagged with the moderator's attention, or directly through [GitHub contact](https://github.com/dvaJi).

This project follows the spirit of the [Contributor Covenant](https://www.contributor-covenant.org).
